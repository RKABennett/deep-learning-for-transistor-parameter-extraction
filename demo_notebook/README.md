## Demo Jupyter Notebook for Transistor Parameter Extraction

This directory contains [demo_notebook.ipynb](./demo_notebook.ipynb), a demo
jupyter notebook for transistor parameter extraction. This notebook will walk 
you through an example extraction. The notebook is functionally the same as
the example presented in the [demo directory](./../demo), but is stitched 
together in one coherent spot to make it (hopefully) easy to follow.

## Installation

First, navigate to the [repo root](./../) and then follow the installation 
instructions for the main package in the [main repo README.md](./../README.md).
Be sure to activate the virtual environment and install the main package with
pip. 

Then, to install jupyter and open the notebook, do the following:

```bash
python3 -m pip install jupyter
jupyter notebook demo_notebook.ipynb
```
